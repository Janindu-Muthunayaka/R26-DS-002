 ┌────────────────────────────────────────────────────────────────────────────────────┐
 │ L7 PERSONALIZATION SERVICE  (/interpret)                                           │
 │                                                                                    │
 │  1. TRANSLATE      Sinhala ──► English            (NLLB, local model)               │
 │                                                                                    │
 │  2. DETECT INTENT  English ──► one label           (LLM: OPENAI_INTENT_MODEL,       │
 │                    ASK_QUESTION, READ_ALOUD,         default gpt-4o-mini)           │
 │                    REPEAT, NEXT, CHANGE_SPEED,                                     │
 │                    SIMPLIFY, GO_TO_PAGE, ...                                       │
 │                                                                                    │
 │  3. FIND MODIFIERS (Sinhala words first, then English)                              │
 │                    repeat? speed? style? pause? part size? volume? summary?         │
 │                                                                                    │
 │  4. SPEED / PAUSE  ┌──────────────────────────────────────────────────────────┐    │
 │     (BOTH paths)   │ if a speed / pause / repeat / part-size word was found,  │    │
 │                    │ the user's saved profile is updated NOW:                 │    │
 │                    │   faster  ► rate x1.10, pause -0.1                       │    │
 │                    │   slower  ► rate x0.90, pause +0.1                       │    │
 │                    │   repeat right after an answer ► rate x0.95, pause +0.1  │    │
 │                    │   "more / fewer pauses"        ► pause +/-0.2            │    │
 │                    │   rate kept in 0.8-1.3, pause_scale in 0.5-2.0           │    │
 │                    └──────────────────────────────────────────────────────────┘    │
 │                                                                                    │
 │  5. ROUTE  (L7's first opinion)                                                    │
 │       delivery only ("speak faster") ...... LOCAL           no style, no learning  │
 │       navigation / control (next, stop) ... SYSTEM_COMMAND  no style, no learning  │
 │       everything else ..................... GENERATE        style decided:         │
 │                                               explicit request > style words >    │
 │                                               user's learned model; learns only   │
 │                                               from explicit evidence              │
 │                                                                                    │
 │  RETURNS: intent, English, route, style + prompt, speed, pause_scale               │
 │                                                                                    │
 │  (L7 down or failing ──► the main server uses its keyword backup instead,          │
 │   same kind of result, marked "stub-fallback")                                     │

 EXAMPLES
 --------
  "වේගයෙන් කතා කරන්න"      speed ↑ pause ↓ (step 4) ► ACTION: "හරි…" + replay
  "හෙමින් සරලව කියන්න"     speed ↓ pause ↑ (step 4) ► GENERATE: previous question, Simple
  "දෙවනි ලිපිය කියවන්න"    (any L7 label)          ► ACTION: article 2 text
  "ලිපිය 2 ගැන කවුද කිව්වේ" question + article        ► GENERATE: from article 2 only
  "නැවත කියන්න"           repeat (step 4: slower)   ► ACTION: replay last answer

 TURN 1 (right after a scan) is generic and the same for everyone: number of articles
 + each article's number and title. It reads no profile and changes no weights.
