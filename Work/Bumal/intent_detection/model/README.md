# intent_classifier_bundle.joblib

Trained offline in Google Colab (not part of this pipeline's live code).

- **Type:** TF-IDF vectorizer + LinearSVC (wrapped in CalibratedClassifierCV
  for probability scores), trained with scikit-learn 1.6.1.
- **Input:** English text (post-NLLB translation) — NOT raw Sinhala.
- **Output:** intent label only. It does NOT predict personalization_flags
  (speed/detail_level/language_style) — Approach 1/2 (the LLM calls) are
  still the only source for those.
- **Training data:** 530 samples generated by Approach 1 (NLLB + Llama3.2:1b),
  17 intent classes. 30 of the 530 were manually added to fix two
  originally under-represented classes (READ_ARTICLE, NAVIGATE_PAGE_NUMBER).
- **Test-set performance:** 89% accuracy, 0.88 macro-F1 (single split);
  0.897 mean macro-F1 across 5-fold cross-validation.
- **Bundle contents:** a dict with keys `"model"` and `"vectorizer"`
  (load with `joblib.load()`, not `pickle.load()`).

To retrain: see the Colab notebook and CSV kept alongside this project
(not included in this folder to keep the pipeline lightweight — ask
if you need them re-added).

IMPORTANT: this bundle was pickled with scikit-learn==1.6.1. Loading it
with a different scikit-learn version will still work but prints an
`InconsistentVersionWarning` and can silently change predictions. Pin
scikit-learn==1.6.1 in this environment to match.
